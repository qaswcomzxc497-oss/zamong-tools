# 자몽스튜디오 직장인 계산기 3종

월급 실수령액 · 출퇴근 유류비 · 고정비 비율을 한 페이지에서 바로 계산하는 무료 웹 도구입니다.
회원가입·설치 없이 동작하는 순수 정적 사이트(HTML/CSS/JS)이며, GitHub Pages로 배포됩니다.

- 배포 주소: https://qaswcomzxc497-oss.github.io/zamong-tools/
- 제작: 자몽스튜디오 (ZAMONG STUDIO)

## 계산기

| 탭 | 입력 | 출력 |
| --- | --- | --- |
| ① 월급 실수령액 | 연봉 또는 월급(세전), 비과세 식대(기본 20만 원), 부양가족 수 | 4대보험·소득세·지방소득세 공제 후 월/연 실수령액, 항목별 공제 내역 |
| ② 출퇴근 유류비 | 왕복 거리, 연비, 유가, 월 출근일수(기본 22일), 월 톨게이트비 | 1일 / 월 / 연간 유류비, 1km당 비용, 월 주유량·주행거리 |
| ③ 고정비 진단 | 월 실수령액, 월세·통신·보험·구독·교통·기타 고정지출 | 고정비 비중(%), 30~40% 권장선 대비 진단, 통장 쪼개기 추천 금액 |

①의 실수령액은 ③으로 바로 넘길 수 있습니다. 입력값은 브라우저에만 저장(localStorage)되며 서버로 전송되지 않습니다.

## 계산 기준 (2026년)

- 국민연금 4.75% (기준소득월액 41만~659만 원), 건강보험 3.595%, 장기요양은 건강보험료의 13.14%, 고용보험 0.9% — 근로자 부담분
- 소득세: 근로소득공제 + 기본공제(1인 150만 원) + 보험료공제 / 표준세액공제 13만 원 중 유리한 쪽, 근로소득세액공제(총급여별 한도) 반영, 지방소득세 10%
- 결과는 참고용 추정치이며, 실제 금액은 회사의 비과세 항목과 연말정산 결과를 따릅니다.

## Google AdSense 연동

1. `index.html`의 `<head>` 주석 안 `adsbygoogle.js` 스크립트를 실제 게시자 ID로 바꿉니다.
2. 각 탭 하단 `<div class="ad-slot" data-ad="...">` 안에 광고 단위 코드를 넣습니다.
   비어 있는 동안에는 CSS(`.ad-slot:empty`)로 자리를 차지하지 않습니다.
